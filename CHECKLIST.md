# ✅ Checklist de Próximos Passos

## 🚀 Imediatamente (Hoje)

- [ ] Verificar se Node.js está instalado: `node -v`
- [ ] Verificar se PostgreSQL está instalado: `psql --version`
- [ ] Criar banco de dados: `CREATE DATABASE sapatos_ecommerce;`
- [ ] Executar schema.sql
- [ ] Testar backend: `cd backend && npm install && npm run dev`
- [ ] Testar frontend: `cd frontend && npm install && npm start`
- [ ] Criar uma conta de teste
- [ ] Fazer uma compra de teste completa
